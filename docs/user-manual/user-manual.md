# 书昀笔记电子书 · 用户使用手册

> 版本：0.3.4　｜　面向技术写作者的桌面笔记应用

「书昀笔记电子书」（sy-note-books）是一款用 Markdown 写作、以「书本/章节」结构组织笔记的桌面应用。你的笔记不是一堆散乱文件，而是有目录、可导航、可导出成 CHM 帮助文件 / 静态网站 / PDF 的「电子书」。

本手册教你从安装到熟练使用全部功能。

---

## 几个核心概念（先记住这些）

- **Workspace（工作区 / 一本书）**：磁盘上的一个文件夹，里面是你的一整本笔记。比如「Java 笔记」「运维手册」各是一个 workspace。
- **章节（Chapter）**：workspace 下的子目录，形如 `01-入门`，是书的一级目录。
- **页面（Page）**：章节里的一个 `.md` 文件，是书中的一页。每个章节都有一个 `index.md` 作为章节首页。
- **白板（Whiteboard）**：内置的画图板（Drawnix），可以在笔记里画流程图、示意图，画完插入到正文。
- **导出**：把整本书或单页导出成 CHM 帮助文件、Nginx 静态网站目录、或 PDF 文件。

> 想让 AI 帮你把乱文档自动整理成一个 workspace？参见项目根目录的 `skills/knowledge-to-workspace/SKILL.md`。

# 快速上手

本节带你 5 分钟完成：安装 → 创建第一本书 → 写第一篇笔记。

## 安装

### Windows

下载发行版的安装包（`.exe` 或 `.msi`），双击运行，按向导完成安装即可。安装后从开始菜单启动「书昀笔记电子书」。

### 首次启动

启动后会看到 **欢迎页**，上面有应用名称「书昀笔记电子书」和描述「面向技术写作者的桌面笔记应用」，以及两个大按钮：

- **新建 Workspace**：创建一本新书。
- **打开文件夹**：打开一个已存在的 workspace 文件夹。

> 第一次使用没有历史记录，所以「最近打开」区域为空。之后每次打开过的 workspace 都会记录在这里，一键再次打开。

## 创建你的第一本书

1. 在欢迎页点击 **新建 Workspace**。
2. 在弹出的对话框里填写：
   - **名称**（必填）：书名，例如 `Java 笔记`。这会成为窗口标题和导出时的书名。
   - **作者**（选填）：你的名字，留空会记为「未知」。
   - **保存路径**（必填）：这本书在磁盘上的存放位置。可以点 **📂 选择** 挑一个空文件夹，或直接输入路径。
3. 点 **创建**。

创建完成后，应用会在你选的路径下生成一本书的骨架：

```
你的路径/
├── workspace.json   ← 元数据（书名、作者等）
├── SUMMARY.md       ← 目录
└── assets/          ← 资源目录
```

此时这本书是空的（没有章节），左侧目录区会显示空白状态。

## 打开已有的书

如果你已经有一个 workspace 文件夹（自己建的、或别人给的、或 AI 整理生成的）：

1. 在欢迎页点 **打开文件夹**。
2. 在系统对话框里选中那个文件夹。
3. 应用会读取其中的 `workspace.json` 和 `SUMMARY.md`，加载出目录结构。

> **合法的 workspace 必须同时包含 `workspace.json` 和 `SUMMARY.md` 两个文件**，缺任何一个都会报错。详见「常见问题」。

## 写第一篇笔记

### 新建一个章节

空书里还没有章节。在左侧目录区点 **新建章节**，输入章节名（例如 `入门`），回车确认。

应用会自动生成带编号的章节目录（如 `01-入门/`），并创建章节首页 `index.md`。

### 开始编辑

点击章节名，右侧编辑器会打开该章节的 `index.md`。直接在编辑器里打字即可，内容会以 Markdown 实时渲染（所见即所得）。

试试输入：

```markdown
# 我的第一个章节

这是一段 **加粗** 文字和一段 `行内代码`。

- 列表项一
- 列表项二
```

### 自动保存

编辑过程中，**底部的状态栏会实时显示保存状态**：

- `保存中` —— 正在写入磁盘。
- `已保存` —— 写入完成。

你**不需要手动保存**，应用会在你停止输入后自动落盘。也可以按 `Ctrl+S` 立即保存。

# 界面与导航

本节介绍应用窗口的各个区域，以及如何高效导航你的笔记。

## 窗口布局总览

打开一个 workspace 后，窗口从左到右、从上到下分为这些区域：

```
┌─────────────────────────────────────────────────────┐
│ 工具栏（主题、搜索、导出、白板等按钮）                  │
├──────────────┬──────────────────────────────────────┤
│              │ 面包屑：书名 › 当前文件名                │
│  侧边栏       ├──────────────────────────────────────┤
│  （目录树）    │                                      │
│              │           编辑区 / 白板区               │
│              │                                      │
│              │                                      │
│  ─────────   ├──────────────────────────────────────┤
│  状态统计     │ 状态栏（编辑器类型 · 行列 · 保存状态）    │
└──────────────┴──────────────────────────────────────┘
```

### 各区域作用

| 区域 | 作用 |
|---|---|
| **工具栏** | 顶部一排按钮，提供全局操作（主题切换、全局搜索、导出、白板入口等）。把鼠标悬停在按钮上会显示功能名称和快捷键。 |
| **侧边栏** | 左侧目录树，展示书 → 章节 → 页面的层级结构，是你导航笔记的主要入口。 |
| **面包屑** | 编辑区上方，显示「书名 › 当前文件名」，告诉你当前在编辑哪本书的哪一页。 |
| **编辑区** | 占据主要面积，Markdown 编辑器或白板画板都在这里。没打开任何文件时显示欢迎/提示页。 |
| **状态栏** | 编辑区底部，显示编辑器类型（Markdown / Whiteboard）、光标行列、保存状态。 |
| **侧边栏底部统计** | 侧边栏最下方，显示「X 章 · Y 页」的数量统计。 |

## 侧边栏（目录树）

### 结构

侧边栏的目录树分三层：

```
📚 Java 笔记（书）
├── 📁 01-入门（章节）
│   ├── 📄 首页（index.md）
│   └── 📄 快速开始（页面）
├── 📁 02-并发（章节）
│   └── 📄 首页（index.md）
└── ...
```

- 点击 **书名 / 返回按钮** 可以回到 workspace 管理页（欢迎页），切换或新建别的书。
- 点击 **章节** 可以展开 / 折叠它的子页面。
- 点击 **页面** 会在右侧编辑器打开它。

### 选中状态

- 当前打开的页面会**高亮**显示在目录树里。
- 点击另一个页面时，前一个自动取消高亮，新点击的高亮。

### 折叠 / 展开侧边栏

- 点击侧边栏的 **收起按钮**（通常在侧边栏右上角），侧边栏会折叠成一条窄的图标栏，给编辑区让出更多空间。
- 折叠后点击 **展开按钮** 恢复完整侧边栏。
- 折叠状态会被**记住**，下次打开应用时保持。

### 调整侧边栏宽度

侧边栏和编辑区之间有一条 **拖拽分隔条**。把鼠标移到分隔条上，按住左键左右拖动，可以自由调整侧边栏宽度。调整后的宽度也会被记住。

> 章节的增删改等操作详见「章节与页面管理」。

## 面包屑

编辑区正上方有一条面包屑导航：

```
Java 笔记 › 快速开始
```

- 左侧是 **书名**（来自 `workspace.json` 的 `title`）。
- 右侧是 **当前文件名**（来自该 `.md` 的标题）。
- 作用：一眼看清自己在编辑哪本书的哪一页。切换文件时面包屑会同步更新。

## 状态栏

编辑区底部状态栏从左到右通常显示：

| 内容 | 含义 |
|---|---|
| `Markdown` / `Whiteboard` | 当前编辑区是什么模式。 |
| `行:列` | 光标所在行和列。 |
| `保存中` / `已保存` / `保存失败` | 当前的保存状态。 |

- 正常写作时显示 `已保存`。
- 输入时短暂显示 `保存中`，落盘后回到 `已保存`。
- 若磁盘写入失败（如文件被占用、权限不足），会显示 `保存失败`，同时右下角通常会有 Toast 提示。

## 主题切换

- 工具栏上有 **主题切换按钮**（太阳/月亮图标）。
- 点击在 **亮色（light）** 和 **暗色（dark）** 之间切换。
- 切换会立即生效并**持久化**，下次启动保持你上次的选择。

## 视图状态（没有打开文件时）

应用有几种视图状态，会根据当前情况自动切换：

| 状态 | 何时出现 |
|---|---|
| **Welcome（欢迎页）** | 启动时、或关闭所有 workspace 后。显示应用介绍和「新建 / 打开」按钮，以及最近打开列表。 |
| **WorkspaceEmpty（空书）** | 打开了 workspace 但还没选中任何文件。侧边栏可见，编辑区提示「从左侧选择一个文件开始编辑」。 |
| **Markdown（编辑器）** | 选中了一个 `.md` 页面，显示 Vditor 编辑器。 |
| **Whiteboard（白板）** | 进入白板画图模式，全屏画板。 |

## Toast 提示

某些操作（保存失败、导出完成、删除成功等）后，窗口右下角会浮现一条短暂的消息条（Toast），几秒后自动消失。留意它能帮你确认操作结果。

# 编辑笔记

本节介绍 Markdown 编辑器的用法、保存机制，以及工具栏的功能。

## 编辑器概览

书昀笔记的编辑器基于 **Vditor**，采用 **即时渲染（IR）模式**：你输入 Markdown 语法的同时，内容会立即渲染成富文本样式（标题变大、列表变成项目符号、代码块带高亮），但底层保存的始终是纯 Markdown。

打开任意一个 `.md` 页面后，编辑器会出现在右侧主区域。底部状态栏会显示 `Markdown` 字样、光标行列、保存状态。

## 工具栏

编辑区上方的工具栏提供常用格式化操作，分了几组：

### 撤销 / 重做

| 按钮 | 快捷键 | 作用 |
|---|---|---|
| 撤销 | `Ctrl+Z` | 撤销上一步编辑。 |
| 重做 | `Ctrl+Y` | 重做被撤销的操作。 |

### 文本格式

| 按钮 | 作用 | Markdown 语法 |
|---|---|---|
| 标题 | 弹出**标题选择器**，选 H1~H6 | `# 标题` ~ `###### 标题` |
| 加粗 | `Ctrl+B` | `**加粗**` |
| 斜体 | `Ctrl+I` | `*斜体*` |
| 删除线 | `Ctrl+D` | `~~删除线~~` |

> 标题按钮点击后会展开一个**标题级别选择面板**，按 `Esc` 可关闭它。

### 块级元素

| 按钮 | 作用 | Markdown 语法 |
|---|---|---|
| 无序列表 | 项目符号列表 | `- 项目` |
| 有序列表 | 数字编号列表 | `1. 项目` |
| 任务列表 | 勾选框列表 | `- [ ] 任务` |
| 引用 | 引用块 | `> 引用` |
| 分隔线 | 水平分隔线 | `---` |

### 代码

| 按钮 | 作用 | Markdown 语法 |
|---|---|---|
| 代码块 | 多行代码（可指定语言） | ` ```javascript ... ``` ` |
| 行内代码 | 行内的代码片段 | `` `代码` `` |

> 代码块支持语言标识，例如 ` ```python `，编辑器会按语言做语法高亮。

### 链接与表格

| 按钮 | 快捷键 | 作用 |
|---|---|---|
| 链接 | `Ctrl+K` | 插入超链接 `[文字](地址)` |
| 插入表格 | — | 弹出**表格网格选择器**，拖选行列数快速建表 |
| 白板画图 | `Ctrl+Shift+D` | 进入白板画图模式（详见「白板画图」） |

> 插入表格按钮点击后弹出网格选择器，鼠标拖过若干格即确定表格大小，按 `Esc` 可取消。

### 右侧功能按钮

工具栏最右侧还有几个全局功能按钮（与分隔线分开）：

| 按钮 | 快捷键 | 作用 |
|---|---|---|
| 目录 | — | 开关**浮动目录**面板，列出当前文档的标题大纲，点击可跳转。 |
| 搜索 | `Ctrl+Shift+F` | 打开全局搜索。 |
| 导出 | `Ctrl+P` | 打开导出对话框。 |
| 切换主题 | — | 切换亮色 / 暗色主题。 |

## 浮动目录（TOC）

点击工具栏的 **目录** 按钮，会弹出一个浮动面板，列出当前这篇笔记里的所有标题（H1~H6），层级缩进显示，类似 GitBook 风格。

- 点击任意标题，编辑器会滚动到对应位置。
- 再次点击目录按钮可关闭面板。

适合在长文档里快速跳转。

## 图片

笔记里的图片有两类来源：

1. **白板插图**：在白板里画好后「保存并插入」，会自动以 `![img-NNN](./assets/xxx.svg)` 形式插入正文。详见「白板画图」。
2. **外部图片**：你也可以手动用 Markdown 图片语法 `![描述](路径)` 引用 `assets/` 目录里的图片文件。

> 鼠标悬停在正文里的白板图片上时，可能会出现**悬浮预览**。图片资源的命名与存放规则属于 workspace 结构规范，普通写作时无需关心，应用会自动处理。

## 自动保存

### 保存机制

- 编辑器采用**自动保存**：你停止输入后，应用会自动把内容写入磁盘。
- 状态栏实时反映保存进度：
  - 输入时 → `保存中`
  - 落盘完成 → `已保存`
  - 写入失败 → `保存失败`（通常伴随右下角 Toast 提示）
- 也可以按 `Ctrl+S` **立即保存**，状态栏会显示 `已保存`。

### 保存失败怎么办

出现 `保存失败` 通常是以下原因：

- 文件被其它程序占用（如外部编辑器同时打开）。
- 磁盘空间不足或权限问题。
- 文件路径包含非法字符。

关掉占用程序、检查权限后重试即可。

## 文件切换

- 在左侧目录树点击另一个页面即可切换。
- 切换时：面包屑更新为新书名 › 新文件名，编辑器加载新内容。
- 当前未保存的内容会**先自动保存**再切换，不会丢失。

## 写作小贴士

- **首行写 H1 标题**：每个 `.md` 第一行建议是 `# 标题`，它会作为该页面在目录树和面包屑里显示的名字。
- **善用代码块语言标识**：写 ` ```javascript ` 比 ` ``` ` 显示效果更好。
- **长文档用目录跳转**：开启浮动目录面板快速导航。
- **跨页引用**：可以用相对路径链接到其它页面，例如 `[详见并发章](../02-并发/线程基础.md)`。注意路径要相对当前文件正确。

# 白板画图

本节介绍如何用内置白板（Drawnix）在笔记里画流程图、示意图、手绘，并把画好的图插入正文。

## 什么是白板

白板是一个内置的**全屏画图工具**，基于开源项目 Drawnix / Plait 画板引擎。你可以在上面绘制形状、连线、文字等，画完后一键插入到当前 Markdown 笔记中，成为正文里的一张可编辑插图。

**关键特点：**

- **可再编辑**：插入的白板图保存为 `.drawnix`（矢量数据）+ `.svg`（预览）两个文件，以后还能重新进入白板修改，不会丢元素。
- **矢量清晰**：导出 CHM / PDF 时白板图保持矢量级清晰度。

## 进入白板

有三种方式进入白板：

| 方式 | 操作 |
|---|---|
| 工具栏按钮 | 点击工具栏的 **白板画图** 按钮。 |
| 快捷键 | 在编辑器里按 `Ctrl+Shift+D`。 |
| 编辑已有图 | （如支持）在正文里对白板图进行再编辑时进入。 |

进入后：

- 侧边栏、工具栏**自动隐藏**，画板占据整个窗口。
- 顶栏（白板顶栏）出现三个元素：**← 返回** 按钮、当前文档标题提示、**保存并插入** 按钮。

## 画板界面

### 白板顶栏

| 元素 | 作用 |
|---|---|
| **← 返回** | 退出白板回到编辑器。若有未保存绘制会弹出确认。 |
| 标题提示 | 显示你正在为哪个文档绘图。 |
| **保存并插入** | 把当前画板内容保存，并插入到正文。保存中按钮显示「保存中...」。 |

### 绘图工具

绘图工具位于 Drawnix 画板自带的面板上，通常包括选择、自由画笔、基本图形（矩形、椭圆、直线、箭头等）、文本等。具体可用工具以画板界面实际显示为准。把鼠标悬停在工具图标上查看其名称。

### 画布

- 画布是一个可无限延伸的二维平面，可以**滚动、缩放**浏览。
- 用选中的工具在画布上拖拽即可绘制。
- 快速连续绘制是安全的（应用有防崩溃保护，不会因快速操作而崩溃）。

## 绘制与编辑

1. 在工具面板选一个绘图工具。
2. 在画布上按住鼠标拖拽，画出形状 / 线条。
3. 切换到**选择工具**可以移动、调整已绘制的元素。
4. 反复修改直到满意。

> 白板里的所有操作都实时保留在画板上，直到你「保存并插入」或放弃。

## 保存并插入

画好后点顶栏的 **保存并插入**：

1. 应用把画板数据序列化成 `.drawnix` 文件，并渲染出 `.svg` 预览图。
2. 这两个文件保存到**当前文档所在章节的 `assets/` 目录**，文件名形如 `<文档名>-img-001.drawnix` / `<文档名>-img-001.svg`。
3. 应用自动在正文里光标位置插入一行 Markdown 图片引用：`![img-001](./assets/xxx-img-001.svg)`。
4. 成功后右下角提示「保存并插入成功」，自动退出白板回到编辑器。

回到编辑器后，你就能在正文里看到刚画的图。

## 放弃返回

如果在白板里画了东西但不想保存：

1. 点顶栏 **← 返回**，或按 `Esc`。
2. 若有未保存的绘制，会弹出**确认对话框**：
   - 标题：「放弃当前绘制？」
   - 内容：「未保存的内容将会丢失。」
   - 按钮：**放弃并返回** / **取消**。
3. 点 **放弃并返回** 确认丢弃，返回编辑器；点 **取消** 留在白板继续画。

> 没有任何未保存改动时，直接返回不会弹确认。

## 白板模式下的快捷键

进入白板后，编辑器相关的全局快捷键会被**拦截**，避免误触：

- 白板中按 `Ctrl+Shift+F` **不会**打开全局搜索。
- 白板中按 `Ctrl+P` **不会**打开导出。
- 白板中按 `Esc` 触发返回流程（有改动则弹确认）。

这样你在画图时可以放心使用键盘，不会跳出干扰。

## 白板图在导出时的表现

白板图本质是 SVG，导出时：

- **PDF 导出**：SVG 矢量图直接嵌入，清晰锐利。
- **CHM 导出**：SVG 会被自动转换为 PNG（CHM 格式对 SVG 支持有限），保证在 Windows 帮助查看器里正常显示。转换只替换图片引用，不会改动正文文字。
- **Nginx 网站导出**：SVG 原样输出，浏览器原生支持。

## 小贴士

- **复杂图分多张**：一张图别塞太多元素，画不清就拆成几张，分别「保存并插入」。
- **图片会按序号编号**：同一文档里的多张白板图依次 `img-001`、`img-002`……不要手动重命名以免关联断裂。
- **再编辑**：需要修改已插入的白板图时，重新进入白板（应用会载入该图对应的 `.drawnix` 数据），改完再保存即可，不会生成新文件。

# 搜索

本节介绍如何用全局搜索快速找到笔记里的内容。

## 打开搜索

| 方式 | 操作 |
|---|---|
| 快捷键 | `Ctrl+Shift+F`（推荐） |
| 工具栏 | 点击工具栏的 **搜索** 按钮 |

搜索会弹出一个居中的搜索对话框，覆盖在当前界面上。

> 在**白板模式**下，`Ctrl+Shift+F` 会被拦截，不会打开搜索。先退出白板再搜。

## 搜索对话框

### 输入框

- 顶部输入框，placeholder 为「搜索全部文档...」。
- 输入关键词后**立即搜索**，无需回车。
- 输入框右侧提示快捷键 `Ctrl+Shift+F`。

### 结果区域

每条搜索结果包含：

| 部分 | 内容 |
|---|---|
| **标题** | 匹配文档的标题。 |
| **面包屑** | 该文档在目录树中的位置（书 › 章节 › 页面）。 |
| **摘要片段** | 匹配处附近的正文片段，命中关键词用**高亮**（`<mark>`）标出。 |

- 鼠标悬停在某条结果上会高亮预选。
- **当前选中的结果**带 `selected` 高亮样式。

### 没有结果时

输入了关键词但没匹配到任何内容，结果区显示「未找到匹配内容」。

## 过滤范围（选项卡）

输入框下方有一排过滤选项卡，控制在哪里搜：

| 选项卡 | 搜哪里 |
|---|---|
| **全部** | 文件名 + 正文内容（默认）。 |
| **文件名** | 只在文件名 / 标题里搜。 |
| **内容** | 只在正文内容里搜。 |

- 点击选项卡切换范围，结果立即刷新。
- 也可按 `Tab` 键在三个范围间循环切换。

## 键盘导航（高效操作）

搜索对话框完全支持键盘操作，熟练后不用碰鼠标：

| 按键 | 作用 |
|---|---|
| `↑` / `↓` | 上移 / 下移选中结果。 |
| `Enter` | 打开当前选中的结果文件，并关闭搜索。 |
| `Tab` | 切换过滤范围（全部 → 文件名 → 内容 → 全部）。 |
| `Esc` | 关闭搜索对话框。 |

- 打开结果后，编辑器会加载该文件，光标定位到匹配处。
- 鼠标点击某条结果也能直接打开它。

## 结果数量提示

搜索对话框底部有一行 **footer**：

- 左侧：`找到 N 个结果`。当结果数量超过上限（最多显示 7 条）时，会追加提示「（仅显示前 7 个，输入更精确的关键词缩小范围）」。
- 右侧：快捷键提示 `↑↓ 导航 · Enter 打开 · ESC 关闭 · Tab 切换范围`。

> 结果太多时，建议加长关键词或换用「文件名 / 内容」过滤范围来缩小结果集。

## 索引机制（了解即可）

- 打开一个 workspace 时，应用会**自动构建搜索索引**，扫描所有 `.md` 文件，所以第一次搜索前已完成索引。
- 你编辑、保存文件后，索引会**增量更新**，无需手动重建。
- 新增 / 删除章节或页面时，目录树刷新后索引也会同步重建。
- 搜索在本地内存中完成，断网也能用。

## 关闭搜索

| 方式 | 操作 |
|---|---|
| 快捷键 | `Esc` |
| 点击遮罩 | 点击搜索对话框之外的半透明遮罩区域 |
| 打开结果 | 选中结果按 `Enter`，打开文件的同时关闭搜索 |

# 导出

本节介绍如何把你的笔记导出成 CHM 帮助文件、Nginx 静态网站目录，或 PDF 文件。

## 三种导出格式

| 格式 | 图标 | 适用场景 | 范围 |
|---|---|---|---|
| **CHM** | 📘 | Windows 帮助文件，可在 Windows 上双击打开，带左侧目录树，适合做离线手册分发。 | 整本书或单个章节 |
| **Nginx** | 🌐 | 一套静态 HTML 网站目录，可部署到 Nginx 等 Web 服务器在线访问，也可直接用浏览器打开。 | 整本书或单个章节 |
| **PDF** | 📄 | 把**当前打开的单个文件**导出成一个 PDF。 | 当前文件 |

## 打开导出对话框

| 方式 | 操作 |
|---|---|
| 快捷键 | `Ctrl+P`（推荐） |
| 工具栏 | 点击工具栏的 **导出** 按钮 |

> 在**白板模式**下，`Ctrl+P` 会被拦截，不会打开导出。先退出白板。

## 导出流程

导出对话框分步骤推进，不同情况起点不同。

### 起点：已打开 workspace

如果当前已经打开了一本书，导出对话框直接进入 **配置步骤**。

### 起点：没有打开 workspace

如果当前没有打开任何 workspace（停在欢迎页），导出对话框会先进入 **「选择 Workspace 导出」** 步骤：

- 列出「最近打开」的 workspace，点选一个进入配置。
- 若没有任何最近记录，会提示「没有最近打开的 Workspace。请先打开一个 Workspace 再导出。」

## 配置步骤

### 选择导出类型

三张卡片：**📘 CHM** / **🌐 Nginx** / **📄 PDF**，点击选中（选中的卡片带 `selected` 高亮）。

- 选 **CHM** 或 **Nginx** 后，下方出现范围与覆盖选项。
- 选 **PDF** 后，下方提示「将当前打开的文件直接生成为 PDF 文件。点击导出后选择保存位置。」（PDF 不需要选范围）。

### 导出范围（仅 CHM / Nginx）

下拉选择：

| 选项 | 含义 |
|---|---|
| **整个 Workspace** | 导出整本书。 |
| *某个章节名* | 只导出指定的单个章节。 |

### 书名 / 作者覆盖（可选，仅 CHM / Nginx）

- **书名覆盖**：留空则使用 `workspace.json` 里的书名；填了就用你填的。
- **作者覆盖**：同理，留空用原作者。

> 适合在不改动原 workspace 的前提下，临时给导出物换个标题或署名。

### 开始导出

点底部按钮启动：

- CHM / Nginx：按钮文字 **「开始导出」**。
- PDF：按钮文字 **「导出 PDF」**。

## 进度步骤

点开始导出后进入进度界面：

- 一条**进度条**实时推进。
- 进度文字显示当前阶段（如「正在生成 HTML…」）。
- 细节信息显示更具体的处理内容。

导出过程中请耐心等待，不要关闭对话框。

## 完成与失败

### 导出成功

显示 ✅ 和「导出成功」，并给出输出路径。提供三个操作：

| 按钮 | 作用 |
|---|---|
| **另存为...** | 弹出目录选择器，把导出产物复制一份到你指定的位置。 |
| **打开文件夹** | 在系统文件管理器里打开导出产物所在的目录。 |
| **关闭** | 关闭对话框。 |

### 导出失败

显示 ❌ 和「导出失败」，并显示错误信息。可点 **重试**（若提供）重新导出，或关闭后排查问题。

常见失败原因见「常见问题」。

## CHM 导出细节

- CHM（Compiled HTML Help）是 Windows 原生帮助格式，导出后是一个 `.chm` 文件。
- **目录结构**：CHM 的左侧目录树直接对应你书的 `SUMMARY.md`（章节 → 页面）。
- **语言**：CHM 的语言标识从 `workspace.json` 的 `language` 字段读取（中文 `0x0804`，英文 `0x0409` 等），不是硬编码，所以中英文书都能正确显示。
- **图片兼容**：CHM 对 SVG 支持有限，导出时正文里的**白板 SVG 图会自动转换为 PNG**，保证在 Windows 帮助查看器里正常显示。转换只替换图片引用，不改动正文文字。
- **CHM 编译器**：生成 `.chm` 需要系统里有 CHM 编译器（如 Windows 上的 `hhc.exe`）。
  - 编译器可用时：产出真正的 `.chm` 文件。
  - 编译器不可用时：产出**未编译的 CHM 项目目录**（含 `.hhp` / `.hhc` / HTML 文件），你可以自行编译或直接用浏览器查看其中的 HTML。

## Nginx 导出细节

- 产出的是一个**静态网站目录**，内含若干 HTML、CSS、图片。
- 直接用浏览器打开其中的首页 HTML 即可浏览。
- 也可把整个目录部署到 Nginx / 任意静态 Web 服务器对外提供访问。
- 白板 SVG 图保持矢量原样输出（浏览器原生支持 SVG）。

## PDF 导出细节

- 把**当前正在编辑的那个文件**导出成一个 PDF。
- 不涉及章节范围选择（只导出当前一页）。
- 支持书名覆盖（标题会体现在 PDF 里）。
- 点击「导出 PDF」后选择保存位置即可。
- 产出的 PDF 包含正文真实文本内容，长文档会分多页；PDF 文件结构完整（含 `%%EOF` 结尾标记）。
- 白板图以矢量形式嵌入，清晰锐利。

## 版本管理

CHM 和 Nginx 这类整本导出，应用会对导出产物做**版本管理**：

- 每次导出会生成带**递增版本号**的输出目录（避免覆盖上次结果）。
- 版本号按**导出类型独立计数**（CHM 的版本号和 Nginx 的互不影响）。
- 系统会**只保留最近 3 个版本**，更早的自动清理，防止占用过多磁盘。

> 你不需要手动管理这些版本目录，导出成功时点「打开文件夹」就能定位到当前产物。

## 小贴士

- **先预览再分发**：CHM 导出后先双击打开确认排版无误，再分发给别人。
- **PDF 只导单页**：想导出多页 PDF，目前需要逐个文件导出；要整本书，用 CHM 或 Nginx。
- **图片检查**：导出前确认正文里的白板图都能正常显示（编辑器里看得见就行），避免导出物缺图。

# 章节与页面管理

本节介绍如何管理书的目录结构：新建、重命名、删除章节和页面，以及调整章节顺序。

## 层级关系回顾

```
书（workspace）
├── 章节（chapter）= 一个子目录，形如 01-入门/
│   ├── index.md（章节首页，固定存在）
│   └── 页面（page）= 章节 .md 文件
└── ...
```

- **章节** = 书的一级目录项。
- **页面** = 章节下的单篇笔记。
- 每个章节都有一个 `index.md` 作为首页，代表「这个章节本身」。

## 新建章节

1. 在侧边栏点 **新建章节** 按钮（通常在侧边栏顶部或文件树区域）。
2. 输入章节标题（如 `入门`），回车确认。
3. 应用会：
   - 生成带编号的章节目录（如 `01-入门/`），编号自动递增。
   - 创建 `index.md` 作为章节首页。
   - 在 `SUMMARY.md` 里追加这个章节条目。

新建后该章节出现在目录树里。

> 编号是两位数字前缀（`01-`、`02-`…），决定了章节的排列顺序。

## 右键菜单

在目录树里**右键点击**一个章节，会弹出上下文菜单，包含三项操作：

| 菜单项 | 作用 |
|---|---|
| **新建子页面** | 在该章节下新建一个页面（.md 文件）。 |
| **重命名** | 修改章节标题。 |
| **删除** | 删除整个章节。 |

> 页面（文件）同样支持右键操作。把鼠标移到不同节点上右键，菜单会针对该节点类型提供相应操作。

### Esc 关闭菜单

右键菜单打开后，按 `Esc` 或点击菜单外区域可关闭它。

## 新建子页面

1. 右键章节 → **新建子页面**。
2. 输入页面标题，回车确认。
3. 应用在该章节目录下创建对应的 `.md` 文件，并在 `SUMMARY.md` 的该章节下追加页面条目（缩进显示）。

新页面创建后会自动选中，右侧编辑器打开它，可以直接开始写。

## 重命名

### 操作

1. 右键节点 → **重命名**。
2. 节点标题处会变成一个**内联编辑框**，框里预填当前名称。
3. 修改后：
   - **回车** 确认修改。
   - **Esc** 或点击别处 取消。
4. 确认后，应用更新文件标题和 `SUMMARY.md` 里的条目文字。

### 说明

- 重命名改的是**显示标题**（`.md` 的 H1 和 SUMMARY 里的文字）。
- 章节目录的 `NN-slug` 名字是否随之改变，取决于实现；无论如何显示标题都会正确更新。

## 删除

### 操作

1. 右键节点 → **删除**。
2. 弹出**确认对话框**：
   - 标题：「确认删除」
   - 内容：「确定要删除「{名称}」吗？」，若是章节还会追加「将删除文件夹及所有内容。」
   - 按钮：**删除** / **取消**
3. 点 **删除** 确认，**取消** 放弃。

### 注意

- 删除**章节**会删除整个文件夹及其下所有页面，**不可恢复**（不进回收站），所以删除章节前务必确认。
- 删除**页面**只删该单个 `.md` 文件。
- 删除后 `SUMMARY.md` 会同步移除对应条目。

## 章节展开 / 折叠

- 点击章节名（文件夹图标节点）可**展开 / 折叠**它的子页面列表。
- 展开时显示子页面，折叠时只显示章节本身。
- 展开状态便于浏览，折叠状态便于在章节很多时快速定位。

## 调整章节顺序

章节的排列顺序由目录名前的 **`NN-` 编号前缀**决定。调整顺序的本质是重新分配这些编号。

应用提供 **章节排序（reorder）** 功能：

- 你指定新的章节顺序后，应用会：
  1. 把每个章节目录的 `NN-` 前缀换成新的编号（**保留后面的 slug 不变**），例如 `01-intro` → `02-intro`。
  2. 为避免重命名时**撞名**，采用**两阶段重命名**（先全部改成临时名，再改成最终名），保证中间过程不会冲突。
  3. 自动更新 `SUMMARY.md` 里所有路径，使目录树指向重命名后的章节。

### 安全保障

- 排序操作会**校验路径**，拒绝任何试图逃逸出 workspace 的路径（含 `..` 路径穿越），防止越权改动。
- 章节内部的文件（页面、assets 资源）在排序时**原样保留**，只改章节目录名和 SUMMARY 引用。

## 章节统计

侧边栏最下方显示这本书的数量统计：**「X 章 · Y 页」**。

- **章** = 章节数量。
- **页** = 所有页面的总数（含各章节的 index.md）。

新建 / 删除章节或页面后，统计会实时更新。

## 目录树缺失项

如果 `SUMMARY.md` 里列了某个路径，但磁盘上对应文件**不存在**了，该条目在目录树里会以 **红色 / missing 标记**显示，提示你该文件缺失。

- 这种情况通常是你在外部删除了文件，或 `SUMMARY.md` 被手动改错。
- 解决：要么补回缺失的文件，要么编辑 SUMMARY 移除该条目（推荐在应用内操作）。

## 小贴士

- **编号即顺序**：想让某章排前面，就给它小编号。批量调顺序用应用的排序功能，别手动改前缀（容易撞名）。
- **章节主题单一**：一章一个主题，内容多就拆多页，不要一个章节塞所有内容。
- **外部改动需刷新**：如果你在应用外手动改了 workspace 文件，回到应用后目录树 / 搜索索引可能需要刷新才反映最新状态。
- **SUMMARY 由应用维护**：`SUMMARY.md` 顶部有三行「请勿手动编辑」注释，建议始终在应用内做增删改操作，避免手动编辑导致解析异常。

# 快捷键速查表

所有快捷键一览。Windows 用 `Ctrl`；若你在其它平台，`Ctrl` 对应 `Cmd`（macOS）。

## 全局

| 快捷键 | 作用 | 备注 |
|---|---|---|

# 常见问题（FAQ）

## 打开与加载

### Q：打开文件夹时报错「路径不存在」/「路径不是目录」

- 你选的路径不存在，或选中的是一个**文件**而非**文件夹**。
- workspace 必须是一个**目录**，请选择包含 `workspace.json` 和 `SUMMARY.md` 的那个文件夹。

### Q：报错「缺少 workspace.json」/「缺少 SUMMARY.md」

一个合法的 workspace 必须**同时包含**这两个文件：

- `workspace.json`：书的元数据（书名、作者、语言等）。
- `SUMMARY.md`：目录树。

缺任何一个都无法打开。如果你是手动建的 workspace，请补齐这两个文件；或用应用的「新建 Workspace」重新创建一本，再把内容迁进去。完整的 workspace 结构规范见项目根目录 `skills/knowledge-to-workspace/SKILL.md`。

### Q：报错「workspace.json 损坏」

`workspace.json` 必须是合法的 JSON。手动编辑时多写/少写了逗号、引号会导致解析失败。请用 JSON 校验工具检查格式，或用应用新建一个标准 workspace.json 比对。

### Q：最近打开列表里点了某项打不开

该 workspace 可能已被移动、重命名或删除。请在文件管理器里确认它还在不在，再用「打开文件夹」重新定位。

## 目录树

### Q：目录树里某些条目显示为红色 / missing

`SUMMARY.md` 里列了该路径，但磁盘上对应文件不存在。常见原因：

- 在应用外删除了文件，但 SUMMARY 没同步。
- 手动编辑 SUMMARY 写错了路径。
- 用 AI / 脚本生成 workspace 时漏建了文件。

解决：补回缺失文件，或在应用内移除该条目。

### Q：手动改了 SUMMARY.md，目录显示混乱

`SUMMARY.md` 顶部有三行「请勿手动编辑」注释，且有严格的缩进规则（章节顶格、页面缩进 2 空格）。手动改坏缩进、删掉注释行、写残缺的链接都会导致解析丢条目。建议：

- 始终在应用内做增删改。
- 已改坏的情况下，对照正确格式（见 SKILL.md）修复，或用应用重新整理。

### Q：章节顺序乱了，想调整

章节顺序由目录名前的 `NN-` 编号决定。用应用的**章节排序**功能调整，不要手动改前缀（容易撞名）。详见「章节与页面管理」。

## 编辑与保存

### Q：状态栏显示「保存失败」

通常是磁盘写入受阻：

- 文件被外部编辑器 / 程序占用 → 关掉占用程序。
- 磁盘空间不足 → 清理空间。
- 权限不足 → 检查文件夹读写权限。
- 路径含特殊字符 → 把 workspace 移到纯字母路径下。

排除后重新编辑会再次自动保存。

### Q：切换文件后内容丢了？

不会丢。切换前应用会**先自动保存**当前文件再加载新文件。如果遇到内容异常，检查是不是保存失败（状态栏会提示）。

### Q：代码块没有语法高亮

写代码块时记得加**语言标识**，例如：

````markdown
```python
print("hello")
```
````

只写 ` ``` ` 不带语言不会有高亮。

## 白板

### Q：白板里按 Ctrl+Shift+F / Ctrl+P 没反应

这是**设计如此**。白板模式下编辑器相关的全局快捷键被拦截，避免画图时误触。退出白板后快捷键恢复正常。

### Q：白板图在导出的 PDF / CHM 里看不清 / 缺失

- **PDF**：白板图以矢量 SVG 嵌入，应清晰。若缺失，检查编辑器里该图是否正常显示。
- **CHM**：CHM 对 SVG 支持有限，导出时 SVG 会被转成 PNG。若转换失败可能导致缺图，尝试重新导出。
- 确认 `assets/` 里的 `.drawnix` 和 `.svg` 文件成对存在。

### Q：连续画很多笔后应用卡住？

应用有防崩溃保护，正常使用不会因快速绘制崩溃。如遇异常，保存当前绘制后重启应用。

## 搜索

### Q：搜索不到刚写的内容

- 搜索索引在保存文件后增量更新。确认文件已**保存**（状态栏显示「已保存」）。
- 新建章节/页面后目录树刷新，索引会重建。稍等片刻再搜。

### Q：搜索结果太多

每页最多显示 7 条。用**更长的关键词**，或切换到「文件名 / 内容」过滤范围缩小结果。

## 导出

### Q：CHM 导出没有生成 .chm 文件，只有一个文件夹

生成 `.chm` 需要系统里有 **CHM 编译器**（Windows 上的 `hhc.exe`）。编译器不可用时，应用会产出**未编译的 CHM 项目目录**（含 `.hhp` / `.hhc` / HTML）。你可以：

- 安装 CHM 编译工具后重新导出。
- 或直接用浏览器打开项目目录里的 HTML 文件查看。

### Q：导出失败

常见原因：

- workspace 里有缺失文件（目录树红色项）→ 先修复。
- 输出目录无写权限 → 换个有权限的位置。
- 磁盘空间不足。
- 导出范围选择有误（如选了空章节）。

看错误信息里的具体提示对症排查。

### Q：导出的 CHM 中文乱码

CHM 语言从 `workspace.json` 的 `language` 字段读取。确认你的 workspace.json 里 `language` 是 `"zh-CN"`（不是乱填或空值）。

### Q：PDF 只能导出当前一页？

是的，PDF 导出是**单文件**导出，把当前打开的那个 `.md` 生成一个 PDF。想导出整本书请用 CHM 或 Nginx。

### Q：导出产物找不到了

导出成功界面会显示输出路径，点 **「打开文件夹」** 可直接定位。另外整本导出会做版本管理，只保留最近 3 个版本，更早的可能被自动清理——及时用「另存为」把需要的版本复制走。

## workspace 结构

### Q：我能把多个领域的笔记放进一个 workspace 吗？

技术上可以，但**不建议**。一个 workspace 设计为一本「书」，混放多个主题会让目录混乱、导出物杂乱。建议**一个主题一个 workspace**（如 java 一本、python 一本）。

### Q：想让 AI 帮我自动整理 workspace 怎么做？

参考项目根目录 `skills/knowledge-to-workspace/SKILL.md`，它是一份给 AI agent 用的整理规范，能把零散文档分类整理成合法的 workspace。

### Q：workspace.json / SUMMARY.md 能手动编辑吗？

能，但有风险：

- `workspace.json`：合法 JSON 即可，但建议尽量用应用维护。
- `SUMMARY.md`：格式严格（顶部 3 行注释 + 缩进规则），手动编辑容易改坏导致丢条目，**强烈建议在应用内操作**。

## 其它

### Q：折叠侧边栏 / 切换主题后，重启应用又变回去了？

不会。这些设置会持久化保存，重启后保持上次的选择。如果没保持，可能是设置文件写入权限问题。

### Q：应用启动慢 / 大文件编辑卡

应用对大文件（数千行）的读写和索引做了性能优化。若仍卡顿：

- 把超大文档拆成多页。
- 确认没有外部程序同时占用这些文件。
