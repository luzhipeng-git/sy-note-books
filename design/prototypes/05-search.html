架构概览

本文档描述系统的整体架构设计。系统采用微服务架构，API 网关负责路由和认证。

系统组件

系统由以下核心组件构成：

  • API 网关 — 请求路由、认证、限流
  • 业务服务 — 核心业务逻辑处理
  • 数据层 — PostgreSQL + Redis 缓存
  • 消息队列 — RabbitMQ 异步通信

技术选型

后端使用 Go 语言开发，API 网关基于 Kong，前端使用 React 19。
