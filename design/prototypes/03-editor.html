API 总览

本文档描述系统的所有 REST API 端点。基础 URL 为 https://api.example.com/v1

认证

所有 API 请求需要在 Header 中携带 Bearer Token：

Authorization: Bearer <token>

用户接口

以下表格列出了所有可用的用户相关接口：

方法路径说明
GET/users获取用户列表
POST/users创建用户
GET/users/:id获取单个用户

错误处理

  • 400 Bad Request — 请求参数无效

  • 401 Unauthorized — 未携带 Token 或 Token 过期

  • 404 Not Found — 资源不存在

  • 500 Internal Server Error — 服务端异常
