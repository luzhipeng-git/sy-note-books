2. 导出类型差异对比

维度CHMNginxPDF
导出范围 整个 WS / 单章节 整个 WS / 单章节 当前文件
引擎位置 Python 子进程 Python 子进程 WebView printToPDF
输出格式 单个 .chm 文件 目录（含 HTML/JS/CSS） 系统打印对话框 → PDF
耗时预估 5–30 秒 10–60 秒 即开打印对话框
版本管理 dist/{ws}/chm-v{N} dist/{ws}/nginx-v{N} 无（用户自选路径）

版本独立管理：CHM 和 Nginx 版本号互不影响。新导出 chm-v4 → 删除 chm-v1，nginx 版本不变。

5. 导出错误处理

错误场景检测时机反馈方式恢复策略
磁盘空间不足 Rust 写入时 Toast：「磁盘空间不足，导出失败」 显示重试按钮
Python 引擎未找到 子进程启动时 Toast：「导出引擎缺失，请重新安装」 显示帮助链接
引擎执行超时（5 分钟） Rust 超时检测 进度条变红 + 「导出超时」 重试按钮 + 保留 temp/
源文件被删除/移动 引擎读文件时 Toast：「文件不存在：{路径}」 提示检查文件树
用户取消保存对话框 前端 saveAs 返回 无提示 产物仍保留在 dist/ 下
