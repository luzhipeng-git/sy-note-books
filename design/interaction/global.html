3. 全局快捷键体系

快捷键触发条件动作冲突检测
Ctrl+F Markdown 视图 本文档搜索 白板全屏时拦截
Ctrl+R 搜索栏打开时 展开替换输入框 需先 Ctrl+F 打开搜索栏
Ctrl+Shift+F 任意视图 唤起全局搜索对话框 白板全屏时拦截，不触发
Ctrl+Shift+D Markdown 视图 进入白板全屏模式 Empty 视图时提示「请先打开文件」
Ctrl+P Markdown 视图 导出当前文件为 PDF 白板全屏时拦截
Ctrl+S Markdown 视图 手动保存（正常由自动保存处理） 无冲突，防抖已保存则显示「已保存」
ESC 白板全屏 取消并返回编辑器，恢复光标 搜索对话框打开时关闭搜索
快捷键优先级：白板全屏模式拥有最高优先级，仅 ESC 生效。搜索对话框打开时，ESC 关闭搜索，其他快捷键不触发。
