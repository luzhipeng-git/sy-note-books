操作反馈

操作触发方式成功反馈失败反馈
新建章节 Sidebar ＋ 按钮 文件树出现新节点 + 自动选中 + 打开编辑器 Toast：「创建失败：{原因}」
新建子页面 右键 → 新建子页面 文件树章节下出现新页面 + 自动选中 Toast：「标题已存在」
重命名 右键 → 重命名 / 双击 文件树节点名称更新 + SUMMARY.md 同步 恢复原名称 + Toast：「名称已存在」
删除 右键 → 删除 节点消失 + 若删除当前打开文件则切到 Empty Toast：「删除失败：{原因}」
拖拽排序 拖拽章节节点 序号前缀自动重命名 + SUMMARY.md 更新 恢复原位置
